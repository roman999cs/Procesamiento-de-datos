# Procesamiento-de-datos
Dentro de este repositorio sde encontrarán el total de 10 libros los cuales se dividen en:

1. Cadenas de python
2. Tuplas en python
3. Listas en python
4. Conjuntos en python
5. Diccionarios en python
6. Condiciones en python
7. Bucles en python
8. Funciones en python
9. Clases en python
10. Bono correspondiente a la clase

Dentro de cada uno de estos libros podremos ver prácticamente un curso introductorio al lenguaje d programación de python, en estos mismos podremos encontrar subtemas correspondientes a cada tema general los cuales ayudaran a tener un mejor entendimiento y manejo de los temas y así mismo empezar a familiarizarse con el lenguaje.
